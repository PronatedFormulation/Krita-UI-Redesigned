Krita UI Redesign Manual

Pulvergate fork — Krita 6.x / PyQt6 port of the community UI redesign plugin originally by Kapyia and Pedro Reis. Adds live theme following and robustness fixes merged from the Kaledosium fork.

After enabling the plugin and restarting Krita, a Redesign menu appears in the menu bar. All options are checkable and remember their state.

1. Installation

  1. Copy the krita-ui-redesign folder and the krita-ui-redesign.desktop file into Krita’s pykrita folder:
    • Linux: ~/.local/share/krita/pykrita/
    • Windows: C:\Users\USERNAME\AppData\Roaming\krita\pykrita
  2. The .desktop file must sit next to the folder, not inside it.
  3. In Krita: Settings → Configure Krita → Python Plugin Manager → enable Krita UI Redesign.
  4. Restart Krita.

Tip: Settings → Manage Resources → Open Resource Folder… → pykrita opens the correct location.

2. Features and how to use them

Menu item What it does
Borderless Toolbars Removes borders / white lines on toolbars. Can be used on its own. Also applied automatically when Use flat theme is on.
Thin Document Tabs Makes the document tab bar shorter (slimmer tabs).
Use flat theme Applies flat styling to dockers, toolbars, menus, tabs, buttons, status bar, tree views, overview docker, and the welcome page. Colors always follow the active Krita color scheme (Settings → Themes).
NuToolbox Puts a floating, collapsible toolbox pad on the left side of the canvas (borrows Krita’s Toolbox docker). Toggle visibility with the pad’s arrow button or the related action (default shortcut area: settings actions; often bound to T).
NuToolOptions Puts a floating, collapsible tool options pad on the right side of the canvas. Requires Tool Options to live in a docker (see below). Often bound to N.
NuToolOptions requirement: Set Settings → Configure Krita → General → Tools → Tool Options Location to In Docker, then restart Krita once. If this is not set, the plugin will show a message when you try to enable NuToolOptions.

Live theme following

When you change themes under Settings → Themes, the flat theme and NuTools styles rebuild from the current palette and reapply automatically. You do not need to restart Krita or toggle the Redesign options again.

NuTools pads

  • Pads sit on the canvas edge and follow the active document view / subwindow.
  • Use the small arrow button on each pad to collapse or expand the contents.
  • While NuToolbox or NuToolOptions is active, the original docker shells are kept hidden so empty Toolbox / Tool Options panels do not reappear in the docker area.
  • Turning the menu option off returns the docker to Krita’s normal docking UI.

3. What this fork changes

Summary of work relative to the classic Krita UI Redesign plugin:

Krita 6.x / PyQt6 port

  • All PyQt5 imports updated to PyQt6
  • Palette access via QApplication.instance().palette()
  • Qt 6 enum style (QEvent.Type.*, QFrame.Shape.*, Qt.WidgetAttribute.*, etc.)
  • exec_() → exec()
  • Null-checks for widgets that may be missing (welcome page, overview docker, etc.)

Live theme following (Pulvergate)

  • Palette colors are re-read every time styles are built
  • NuTools stylesheets rebuilt from the active palette
  • Application listens for palette/theme changes and refreshes the UI immediately
  • Broader flat coverage: welcome page, overview docker, recent documents / news frames, combo boxes, status bar text, tree views, spin box chrome

Robustness and polish (merged from Kaledosium)

  • Docker hardening: empty Toolbox / Tool Options shells stay hidden while the floating pads are active
  • Tool Options container: floating tool options use a styled rounded container that matches the flat look
  • Borderless Toolbars: independent menu toggle restored (still auto-on with flat theme)
  • Pad polish: tighter margins, ruler-aware left offset, safer collapse button behavior

4. Tips and troubleshooting

  • If NuToolOptions does nothing or shows a dialog: set Tool Options Location to In Docker and restart Krita.
  • If colors look wrong after switching themes: toggle Flat Theme off and on once, or restart Krita (live refresh should handle this, but a restart is a safe reset).
  • If the original Toolbox docker reappears empty: turn NuToolbox off and on again to re-borrow and hide the shell.
  • Shortcuts for Show Toolbox / Show Tool Options can be rebound under Settings → Configure Krita → Keyboard Shortcuts (search for “Show Toolbox” or “Show Tool Options”).
